# alx_travel_app_0x00

This repository contains the `alx_travel_app` Django project, which serves as the backend for an Airbnb-like application.

## Milestone 2: Database Modeling and Data Seeding

This milestone focuses on defining the core database models, creating serializers for data representation, and implementing a management command to seed the database with sample data.

### Project Structure:
- `alx_travel_app/`: The main Django project directory.
    - `airbnb/`: The inner Django project configuration (settings, urls).
    - `listings/`: Django app containing `Listing`, `Booking`, and `Review` models, their serializers, and the `seed` management command.
    - `users/`: Django app containing a custom User model.

### Setup and Run:

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/YOUR_GITHUB_USERNAME/alx_travel_app_0x00.git](https://github.com/YOUR_GITHUB_USERNAME/alx_travel_app_0x00.git)
    cd alx_travel_app_0x00
    ```

2.  **Create a `.env` file:**
    In the project root (`alx_travel_app_0x00/`), create a file named `.env` and add the following content. Replace `your_super_secret_django_key!` with a strong, random string (e.g., generated by `python -c "import secrets; print(secrets.token_urlsafe(50))"`).
    ```ini
    POSTGRES_DB=airbnb_db
    POSTGRES_USER=airbnb_user
    POSTGRES_PASSWORD=airbnb_password
    SECRET_KEY=your_super_secret_django_key!
    DEBUG=True
    ```

3.  **Build and run Docker containers:**
    This command will set up the PostgreSQL database, run Django migrations, create a default superuser (`admin`/`adminpassword`), and execute the data seeder.
    ```bash
    docker compose up --build
    ```
    The command will complete and exit after seeding the database.

### Verifying Seeded Data (Optional):

To verify that the data has been seeded, you can temporarily start the Django development server and access the Django Admin.

1.  **Start the Django development server:**
    In a new terminal (from the project root `alx_travel_app_0x00/`):
    ```bash
    docker compose run --rm --publish 8000:8000 web python alx_travel_app/manage.py runserver 0.0.0.0:8000
    ```
2.  **Access Django Admin:**
    Open your browser and navigate to `http://localhost:8000/admin/`.
    Log in with username `admin` and password `adminpassword`.
    You should see "Listings", "Bookings", and "Reviews" with populated sample data.
3.  **Stop the server:** Press `Ctrl+C` in the terminal where the server is running.
